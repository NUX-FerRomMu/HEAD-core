# HEAD: starting point

HEAD is a terminal-first environment for coordinating development agents. The executable is provisionally `hea`, avoiding the existing Unix `head` command.

Read [the product context](context.md), [architecture](architecture.md), then [the backlog](../specs/backlog.md). Assign one starter spec to begin implementation.

This baseline defines the first working increment: a local ticket backlog and attention queue accessible from the CLI and Neovim. Agent execution and Git review follow later. Nothing is implemented yet.

Keep documentation proportional to the next change. Specify later work when it becomes actionable, rather than freezing the entire product now.
