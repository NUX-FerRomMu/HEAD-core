## Source coverage notes

Independent Core/Neovim → R01; installation-local project configuration → R02; backlog/Kanban/refinement → R03; human assignment/review → R04; code/test/fix lifecycle → R05/R11; per-ticket agents/live chats → R06; Codex/provider independence → R07; Git branches/worktrees → R08; side-by-side review/comments/manual commits → R09/R10; priority queue/aging/next/requeue → R12; context restoration → R13; manual actions/configurable commands → R14; recovery engineering necessary for durable workflow → R15; self-development MVP → R16.

Dynamic extension infrastructure and later graphical clients are explicitly deferred; architecture boundaries keep them possible. User-selected Go/Lua is ADR-001 and is mandatory for every implementation ticket.
